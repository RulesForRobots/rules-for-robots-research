# Roadmap

Open work in this repository only. Work across repositories, and the order of the steps, is in the [front door's roadmap](https://github.com/RulesForRobots/rules-for-robots/blob/main/ROADMAP.md).

## Scope and a first plugin

- Decide the scope with the maintainer, and the first project that would use it. The README's scope section is a starting point, not a decision.
- Then a first plugin, `rfr-research` or narrower, with its stages for `rfr-process`, built the way every plugin is: from a real use, tried on a throwaway repository and then a real project.
